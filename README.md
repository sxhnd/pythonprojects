## Projects

| Project | What it does | Topics |
|---|---|---|
| [Birthday Problem](BirthdayProblem/) | Estimates the birthday paradox with a Monte Carlo simulation and checks it against the exact probability | probability, simulation |

## Running a project

```bash
git clone https://github.com/sxhnd/pythonprojects.git
cd pythonprojects/<project folder>
```

Then follow that project's README. Birthday Problem uses only the standard
library.

## Layout

```
pythonprojects/
└── BirthdayProblem/
```
